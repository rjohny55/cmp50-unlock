# CMP 50HX 10 ГБ

[Главная](../README_RU.md) · [English](10GB.md) · [Версия 20 ГБ](20GB_RU.md)

## Статус

Это исходная и наиболее полно проверенная конфигурация проекта. Целевая карта:
`10de:1e09`, subsystem `10de:1554` либо `1462:371f`, NVIDIA Open
`610.43.03`.

| Возможность | Статус для 10 ГБ |
| --- | --- |
| GSP/RM stockflow | Проверено исходным проектом |
| Полная скорость SM | Проверено |
| CUDA / Tensor | 3584 / 448, проверено |
| RT count | RM сообщает 56; реальные RT-инструкции не разблокированы |
| ReBAR | 16 ГБ BAR1 проверено исходным проектом после холодного старта |
| PCIe Gen2 | Проверено исходным проектом на его x4 host |
| Idle governor | Отдельная необязательная функция; сначала проверять вручную |

Новый `01-cmp50-stockflow.patch` больше не предполагает фиксированный адрес
WPR для конкретного объёма памяти. Он захватывает диапазон WPR, созданный
штатным FWSEC, проверяет его span `0xe00` и использует это значение далее. Это
сохраняет путь 10 ГБ и позволяет работать платам 20 ГБ с другой геометрией.

## Рекомендуемая установка по стадиям

```bash
git clone https://github.com/rjohny55/cmp50-unlock.git
cd cmp50-unlock
sudo ./install.sh --stage stockflow --install-userland

CMP50_PATCH_STAGE=rt bash ./build.sh
CMP50_PATCH_STAGE=rebar bash ./build.sh
CMP50_PATCH_STAGE=gen2 bash ./build.sh
```

Для записи проверенного модуля в initramfs передайте установщику
`--initramfs`. Перед ReBAR нужен холодный старт. Не переходите на следующую
стадию, пока текущая не проходит `sudo ./verify-live.sh`.

## Важное ограничение RT

Патч `02` изменяет только возвращаемое RM количество RT-ядер. На CMP 50HX
ray-query opcode по-прежнему завершается `INVALID_OPCODE`; физическая RT-часть
считается закрытой fuse/floorsweep. Значение 56 нельзя выдавать за работающий
ray tracing.
