# Установка CMP50 для агента

Актуальная инструкция: [README_RU.md](README_RU.md). Проверенный целевой хост:
Ubuntu 24.04, ядро 6.8.0-149-generic, 4× CMP50 20 ГБ, NVIDIA 610.43.03.

1. Сначала проверить ядро, PCI/subsystem ID, headers, Secure Boot, текущий драйвер и место.
2. Сохранить настройки и проверить возможность отката. Не выгружать работающий драйвер.
3. Для полного 32-ГиБ BAR1/P2P пути использовать `install-all.sh --install-deps --allow-experimental-gen2 --p2p`.
4. Если нужен только governor, использовать `install-governor.sh --start-now`: драйвер он не меняет.
5. Перезагрузку выполнять только в согласованное время, после завершения нагрузок.
6. После загрузки проверить VRAM, BAR1, фактическую скорость PCIe, CUDA и службы.
7. Не принимать успешный старт службы или peer-capability за подтверждение всех compute/NCCL тестов.

На неизвестном ядре или при другом GPU не обходить аппаратные проверки.
