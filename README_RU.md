# CMP50 Unlock

[English](README.md) · [Подробности P2P](docs/P2P.md) · [Governor](idle-governor/README.md)

Патчи открытого драйвера NVIDIA для модифицированных **CMP 50HX 20 ГБ / TU102 / SM75**.
Текущая проверенная конфигурация: **Ubuntu 24.04, ядро 6.8.0-149-generic,
модули NVIDIA и пользовательские библиотеки 610.43.03**.

## Проверенный результат

Проверено 9 ноября 2026 года на сервере с четырьмя картами:

| Параметр | Результат |
| --- | --- |
| Видеопамять | 4 × 20480 МиБ |
| BAR1 | **32768 МиБ на каждой карте** — окно 32 ГиБ, а не дополнительная VRAM |
| PCIe | Все четыре карты: Gen2 x16 |
| CUDA peer access | Доступ объявлен для всех 12 направленных пар |
| Служба Gen2 | Успешно завершилась на ядре 6.8.0-149 |
| Governor | Автозапуск, P8 в простое, возврат в P0 под реальной CUDA-нагрузкой |

Актуальный P2P-вариант включает окно BAR1 32 ГиБ и DMA32-совместимые
bootstrap-выделения. BIOS должен выделять достаточно PCI MMIO. Объявленная
возможность peer access сама по себе не подтверждает скорость или корректность
NCCL. Старые замеры доступны в истории Git.

## Установка

```bash
git clone https://github.com/rjohny55/cmp50-unlock.git
cd cmp50-unlock
sudo ./install-all.sh --install-deps --allow-experimental-gen2 --p2p
```

Команда выбирает полный набор P2P/Gen2, собирает модули под текущее ядро,
при необходимости устанавливает официальные библиотеки NVIDIA, настраивает
BAR1 selector 9, initramfs и governor. Создаётся резервная копия для отката.
Работающий драйвер не выгружается, автоматической перезагрузки нет.
Завершите задачи и перезагрузите сервер вручную. После загрузки:

```bash
sudo ./verify-live.sh
python3 ./verify/cuda-smoke.py
systemctl status cmp50-gen2-second-pass cmp-idle-governor
```

Если анлок уже работает и нужен только менеджер питания:

```bash
sudo ./install-governor.sh --start-now
```

Governor использует каталог управления `/data/cmp50-power` панели, сохраняет
существующие настройки, учитывает историю активности драйвера и возвращает
автоматическое управление вентиляторами под нагрузкой и при остановке.
Готовый бинарник собран для glibc Ubuntu/Debian. Другой каталог данных панели
можно указать через `--ai-manager-data-dir /абсолютный/путь`.

## Сборка и откат

`CMP50_PATCH_STAGE=p2p bash ./build.sh` только собирает модули под текущее ядро.
Исходники NVIDIA 610.43.03 закреплены контрольной суммой, порядок патчей задан
явно. Нужны headers текущего ядра, компилятор и поддержка BIOS. Непроверенные
Gen2-ядра и неподходящие PCI/subsystem ID отклоняются. При Secure Boot нужны
подписанные модули. Поддержка проверенного ядра не означает поддержку всех
более новых ядер без тестирования.

Откат: `sudo ./rollback.sh /var/lib/cmp50-unlock/backups/TIMESTAMP` с путём,
который вывел установщик. При изменении драйвера и PCIe необходим доступ к
восстановлению. Не удаляйте проверки PCI ID. Отчёт о числе RT-ядер не включает
физическое выполнение RT-инструкций.
